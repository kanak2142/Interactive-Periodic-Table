# 🔬 ChemQuest – Interactive Periodic Table

ChemQuest is a Python-based graphical application that displays an interactive, color-coded periodic table of all 118 chemical elements. Users can explore the elements and view detailed information through a simple and user-friendly interface.

## ✨ Features

- **Interactive Periodic Table:** Displays all 118 chemical elements arranged according to their groups and periods.
- **Color-Coded Elements:** Uses different colors to represent chemical categories, including alkali metals, alkaline earth metals, transition metals, metalloids, nonmetals, halogens, noble gases, lanthanides, and actinides.
- **Element Information Popups:** Click any element to view its atomic number, name, symbol, group, period, category, and atomic mass.
- **Element Info Finder:** Search for an element by entering its name or chemical symbol.
- **Live Search Highlighting:** Highlights elements whose names or symbols match the search query.
- **Interactive Interface:** Features hover effects, popup windows, and a dark-themed design.

## 🛠️ Technologies Used

- Python 3
- Tkinter
- ttk (Tkinter themed widgets module)

## 📋 Requirements

- Python 3.x
- Tkinter, generally included with standard Python installations.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/kanak2142/Interactive-Periodic-Table.git
```

### 2. Navigate to the Project Directory

```bash
cd Interactive-Periodic-Table
```

### 3. Run the Application

```bash
python PeriodicTable.py
```

If necessary, use `python3 PeriodicTable.py` instead.

## 🧪 How to Use

1. Launch the application.
2. Explore the color-coded periodic table.
3. Click an element to open its information popup.
4. Enter an element's name or symbol in the Element Info Finder.
5. Click **Open Info** or press Enter to view the element's details.
6. Use the live search functionality to highlight matching elements.

## 🎯 Project Objective

The goal of ChemQuest is to make learning about chemical elements more engaging and accessible through an interactive graphical interface. The project also demonstrates the use of Python and Tkinter for desktop application development.
